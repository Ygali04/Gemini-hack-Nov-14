# ComputerAnything

An always-present macOS agent you can ask to do anything. One prompt, with any attachments, starts a team of agents that drive your real apps. They point and draw with a cursor of their own, speak back, ask before anything risky, and get better every time through a learned map of each app.

Powered by Gemini 4 Argon.
